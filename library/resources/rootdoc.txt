This is the documentation for the Scala standard library.

## Package structure

The [[scala]] package contains core types like [[scala.Int]], [[scala.Float]], [[scala.Array]] or [[scala.Option]]
which are accessible in all Scala compilation units without explicit qualification or imports.

Notable packages include:

  - [[scala.collection]] and its sub-packages contain Scala's collections framework
    - [[scala.collection.immutable]] - Immutable, sequential data-structures such as
      [[scala.collection.immutable.Vector]], [[scala.collection.immutable.List]],
      [[scala.collection.immutable.Range]], [[scala.collection.immutable.HashMap]] or
      [[scala.collection.immutable.HashSet]]
    - [[scala.collection.mutable]] - Mutable, sequential data-structures such as
      [[scala.collection.mutable.ArrayBuffer]], [[scala.collection.mutable.StringBuilder]],
      [[scala.collection.mutable.HashMap]] or [[scala.collection.mutable.HashSet]]
    - [[scala.collection.concurrent]] - Mutable, concurrent data-structures such as
      [[scala.collection.concurrent.TrieMap]]
  - [[scala.concurrent]] - Primitives for concurrent programming such as
    [[scala.concurrent.Future]] and [[scala.concurrent.Promise]]
  - [[scala.io]] - Input and output operations
  - [[scala.math]] - Basic math functions and additional numeric types like
    [[scala.math.BigInt]] and [[scala.math.BigDecimal]]
  - [[scala.quoted]] - Macros and metaprogramming: quotes, splices and the TASTy reflection API
    ([[scala.quoted.Quotes]])
  - [[scala.sys]] - Interaction with other processes and the operating system
  - [[scala.util.matching]] - [[scala.util.matching.Regex Regular expressions]]

Other packages exist. See the complete list in the navigation sidebar.

Additional parts of the standard library are shipped as separate libraries. These include:

  - [scala.xml](https://github.com/scala/scala-xml) - XML parsing, manipulation, and serialization (scala-xml.jar)
  - [scala.collection.parallel](https://github.com/scala/scala-parallel-collections) - Parallel collections (scala-parallel-collections.jar)
  - [scala.util.parsing](https://github.com/scala/scala-parser-combinators) - Parser combinators (scala-parser-combinators.jar)
  - [scala.swing](https://github.com/scala/scala-swing) - A convenient wrapper around Java's GUI framework called Swing (scala-swing.jar)

## Automatic imports

Identifiers in the scala package and the [[scala.Predef]] object are always in scope by default.

Some of these identifiers are type aliases provided as shortcuts to commonly used classes. For example, `List` is an alias for
[[scala.collection.immutable.List]].

Other aliases refer to classes provided by the underlying platform. For example, on the JVM, `String` is an alias for `java.lang.String`.
