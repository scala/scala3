# Highlights of the release

- For transparent inline methods, make their inline default value getters also transparent [#27516](https://github.com/scala/scala3/pull/27516)
- Scaladoc: interactive toggle for capture checking content [#26877](https://github.com/scala/scala3/pull/26877)

# New experimental features

- SIP-79 - Implement relaxed null checks under strictEquality  [#26420](https://github.com/scala/scala3/pull/26420)
- Specialized Traits - Permit variance in specialized traits  [#27581](https://github.com/scala/scala3/pull/27581)
- Standard Library - Add `applyUsing` extension methods on function types to the `FunctionN` companion objects [#27295](https://github.com/scala/scala3/pull/27295)
