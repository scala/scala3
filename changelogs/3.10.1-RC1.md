# Highlights of the release

- Bump Scala CLI to 1.18.0 (was 1.17.1) [#27255](https://github.com/scala/scala3/pull/27255)
- Implement SIP-77: Method Block End Markers [#24251](https://github.com/scala/scala3/pull/24251)
