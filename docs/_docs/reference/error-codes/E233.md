# E233: Unreasonable Catch

This warning is emitted when you write a `catch` case that can catch `Error`.

Catching `Error`s, including by catching all `Throwable`s,
can lead to unexpected behavior because an ${hl("Error")} being thrown indicates an unrecoverable problem.

The JDK documentation states that "a reasonable application should not try to catch" `Error`.
The JDK has had a number of bugs around expected behavior when an `Error` is caught, such as `finally` blocks not executing
([source](https://bugs.openjdk.org/browse/JDK-8177802)) and locks remaining locked ([source](https://bugs.openjdk.org/browse/JDK-8318888)).

On some platforms such as Scala.js, such errors will immediately terminate the application and cannot be caught.


---

## Example

```scala sc:fail sc-opts:-Werror,-explain
def foo(): Unit = ???

def bar(): Unit =
  try foo()
  catch case t: Throwable => ???
```

### Solution

Use `NonFatal` from `scala.util.control` to only catch non-fatal throwables:

```scala sc:compile sc-opts:-Werror
import scala.util.control.NonFatal

def foo(): Unit = ???

def bar(): Unit =
  try foo()
  catch case NonFatal(t) => ???
```
