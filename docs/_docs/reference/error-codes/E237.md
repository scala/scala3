# E237: Invalid Multiple Assignment Target

This error is emitted when attempting to do multiple assignments with more than one level of nesting.

You can only assign to multiple variables one level deep.

---

## Example

```scala sc:fail sc-opts:-explain
def example =
  var x = 0
  var y = 1
  var z = 2
  ((x, y), z) = ((3, 4), 5)
```

### Error

```scala sc:nocompile
-- [E052] Type Error: example.scala:3:2 ----------------------------------------
3 |  x = 2
  |  ^^^^^
  |  Reassignment to val x
  |-----------------------------------------------------------------------------
  | Explanation (enabled by `-explain`)
  |- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
  | You can not assign a new value to x as values can't be changed.
  | Reassigment is only permitted if the variable is declared with `var`.
   -----------------------------------------------------------------------------
```

### Solution

```scala sc:compile
// Use a single level
def example =
  var x = 0
  var y = 1
  var z = 2
  (x, y, z) = (3, 4, 5)
```
