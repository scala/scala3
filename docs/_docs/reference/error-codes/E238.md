# E238: Multiple Assignment Shape Mismatch

This error is emitted when the shapes of the source and target of multiple assignment do not match.
---

## Example

```scala sc:fail sc-opts:-explain
def example =
  var x = 0
  var y = 1
  var z = 2
  (x, y, z) = (3, 4)
```

### Error

```scala sc:nocompile
-- [E052] Type Error: example.scala:3:2 ----------------------------------------
3 |  x = 2
  |  ^^^^^
  |  Reassignment to val x
  |-----------------------------------------------------------------------------
  | Explanation (enabled by `-explain`)
  |- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
  | You can not assign a new value to x as values can't be changed.
  | Reassigment is only permitted if the variable is declared with `var`.
   -----------------------------------------------------------------------------
```

### Solution

```scala sc:compile
// Use as many operands on the right-hand side as on the left-hand side
def example =
  var x = 0
  var x = 1
  var x = 2
  (x, y, z) = (3, 4, 5)
```
